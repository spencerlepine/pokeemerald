# Generated audio (AUDIO_READY)

Sounds and songs generated by `../../tools/cry-generator`, `../../tools/sfx-generator` and
`../../tools/music-generator` that passed every hard gate
but are not installed into `../../game` yet. Same layout as the game tree:

- `sound/direct_sound_samples/cries/<slot>.wav`: companion cries, 10512 Hz 8-bit DPCM-exact, same slot and file
  name as the vanilla cry they replace.
- `sound/direct_sound_samples/sw_sfx/<name>.wav`: sound effects, 13379 Hz 8-bit, where `sfx.py install` puts them.
- `sound/songs/midi/<mus_x>.mid`: songs, the exact MIDI `generate.py install` writes into the game (same file
  name as the vanilla song for a hot-swap). The song model in `tools/music-generator/song-schemas/` is the source.
- `previews/{cries,sfx}/<name>.wav`: 44.1 kHz listening copies, as heard in game (reverb, DAC).
- `previews/music/<name>.mp3`: the song as the m4a engine plays it (intro, then the loop three times), 96 kbps.

Each file comes from the spec named in `../mapping/audio_ready.csv`. To ship more:

```bash
python3 wiki/tools/ship_audio.py tools/cry-generator/specs/<name>.yaml   # make (gated) + copy here
python3 wiki/tools/ship_audio.py tools/music-generator/song-schemas/<name>.yaml  # render: no errors, loop check
python3 wiki/tools/mark_audio_ready.py                                   # audio_ready.csv + pending_audio.csv
```

A shipped song is `rewrite_status` GENERATED in `../database/music.csv`.

To put one in the game: `python3 cry.py install specs/<name>.yaml` (or `sfx.py install`, or `generate.py install`), add the row to
`../mapping/audio_done.csv` and run `python3 wiki/tools/mark_audio_done.py`.

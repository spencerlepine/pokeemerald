# mapping/ (hand-written)

Every file is keyed by `emerald_id` (the id from emerald-db) and carries
`swap_kind`, `map_status`, `art_status`. `tools/build.py` merges these onto
emerald-db and writes `database/`. Rows not listed in any file default to
`HOTSWAP / TODO` (or `KEEP` for generic mechanics).

| File | Rows | Extra columns |
|---|---|---|
| `species.csv` | all 386 creatures | `sw_basis` (starwars-db id, `canon:<name>` or `original`), `home_planet`, `sw_description` (datapad concept), `habitat_note` (where Emerald's wild placement doesn't fit the new planet) |
| `characters.csv` | 59 characters + 25 organizations | `sw_title`, `home_planet`, `role`, `canon_note` (how it bends canon), `text_terms` (`OLD=>NEW` pairs used in dialogue and trainer names) |
| `trainer_classes.csv`, `badges.csv`, `types.csv`, `abilities.csv`, `moves.csv`, `items.csv` | | `sw_basis`, `sw_description`, `notes` |
| `locations.csv` | 213 region-map sections | `planet`. Map titles (`map:*`) are derived: location name + room. |
| `glossary.csv` | | `emerald_term, sw_term`: generic words (POKéMON → COMPANION). Wins over names derived from entities. |
| `net_new.csv` | | `id` (`net:*`), `placeholder_from` (Emerald asset or map to copy), `depends_on` (flag / item), `balance_note` |
| `creature_sizes.csv` | all 386 Emerald species | `height_m`, `weight_kg` (the Datapad's Star Wars size; 30.4 m and 2,000 kg at most), `screen_m` (long bodies only: what the front figure's longest side spans on the size screen), `basis` (`canon`, `scaled` or `emerald`), `emerald_height_m` / `emerald_weight_kg` (Emerald's, still used by Low Kick), `notes` (the canon figure). Ported by `tools/port_sizes.py`. |
| `new_species.csv` | the 12 net-new species in the free old-Unown slots | `slot` and `constant` (alias), `sw_name`, types, the six base stats, `copies` (the species whose abilities, learnsets, EXP, catch and egg data it takes), `art_from` and `cry_from` (placeholders until its own art and cry exist), `evolves_from` / `evo_item` (light/dark branches), `height_m`, `weight_kg`, `body_color`, `tint` (placeholder palette: `dark`, `light` or `#RRGGBB`), `regional_dex` / `national_dex` (Datapad numbers). Ported by `tools/port_creatures.py`. |
| `new_moves.csv` | the 3 net-new moves | `constant`, `sw_name`, `clone_of` (the move whose data it copies), `animation` (the `Move_*` script), `description` (two lines, `\n` between). |
| `move_learnsets.csv` | which learnsets get a new move | `species`, `replaces` (the move it takes the place of, same level), `new_move`, `reason`. Also swaps the move in trainer parties and Grand Arena sets of that species. |
| `planets.csv` | one row per planet (19) | `role` (`main`, `side`, `post`), `act`, `arrive_badges`, `arrive_via` (the hyperlane id or `start`), `story`, `new_content`, `notes`. `tools/build.py` adds the bands read from `area_progression.csv` and writes `database/planets.csv`. |
| `habitat_swaps.csv` | one row per species swap on a planet (76) | `planet`, `from_species`, `to_species`, `maps` and `methods` (pipe-separated; empty = every map of the planet, every method), `reason`. Applied by `tools/encounters.py` after the Dune Sea swaps; the target must be native to the planet and within 150 stat points. |
| `wild_extra.csv` | wild slots of areas Emerald does not have (the Hoth tundra) | Emerald's `wild_encounters.csv` columns (`map_id`, `method`, `area_rate`, `slot`, `slot_rate_percent`, `species_id`, levels) plus `note`. Read by `tools/encounters.py`. |
| `new_people.csv` | the net-new people that need a new slot in ../game | `kind` (`walker`: a new object graphics id; `class`: a new trainer class; `trainer`: a net-new trainer in an unplaced Emerald slot), `constant`, `slot`, `symbol`, `sw_name`, `art` (path in ../game and in `art/`), `spec` (walker tool spec), `copies` (whose sheet and graphics info a walker starts from; whose prize money a class takes), `palette_tag`, and for trainers `trainer_class`, `trainer_pic`, `music`, `gender`, `party`, `walker`, `lines`. Ported by `tools/port_people.py`. |
| `people.csv` | one row per person placed by hand (135) | `area` (world yaml id), `yaml_name` / `yaml_index` (the person in that yaml; empty = a new object still to place), `npc_id` (an Emerald object event the person takes over), `kind` (`npc`, `trainer`, `boss`, `story`, `wild`, `vision`, `relic`), `character` (`character:*` or `net:character-*`), `trainer_class`, `trainer_name`, `party` (`species:<id>@<level>` pipe-separated), `flag`, `lines` (texts split by ` / `), `notes`, and for the port: `walker` (the `object-gfx:*` or `net:walker-*` the person uses; empty = a gap, no walker fits yet), `trainer_pic` (`trainer-pic:*`), `trainer_const` (the new `TRAINER_SW_*` slot), `music` (encounter music) and `gender` for trainers and bosses. `tools/build.py` checks the ids, the yaml and the level band and writes `database/people.csv`. |
| `area_progression_extra.csv` | one row per net-new area (`replaces: new` in `world/`, 51) | Emerald's `area_progression.csv` columns (badges, chapter, event, trainer count and band, wild band, `requires`, `gating_notes`) plus `net_id` (the `net:` row that designs it) and `planet`. Merged into `database/area_progression.csv`; `tools/blockout guide` checks each area against it. |
| `hyperlanes.csv` | one row per ship link between two planets | `from_planet`, `from_area`, `from_room` (the hangar, cabin or shuttle station; empty = the ship lands in the open), the same for `to_`, `ship`, `unlock` (`flag:badge0N-get`, `item:hm-*`, `event:<timeline id>`, a ticket item, or empty = open), `story`, `notes`. Not merged into `database/`; read by `tools/blockout` (`check` validates it, `guide` reports it). |
| `objects.csv` | small world objects per planet (78): nature, rocks, props, small structures | `object_id` (`obj:<planet>:<slug>`), `planet`, `name`, `role` (`edge`, `noise`, `landmark`, `walkable`), `hit_box` and `drawn` (cells, W x H; drawn rows above the hit box are walk-behind), `art` (its `world_art.csv` row when it has one, which then holds its model and status), `placeholder` (a sheet of 16x16 placeholder tiles at the drawn size, in `../world/objects/`, for objects with no `world_art.csv` row), `status`, `about`. No art yet (2026-11-04); the rock shapes are kept in `../../tools/object-kit/`. |
| `rooms.csv` | interior room shells: 35 room styles and their 728 kit parts | `room_id` (`room:<style>` or `room:<style>:<part>`), `kind` (`style`, `part`), `style`, `planet`, `name`, `part`, `size` (drawn size in cells, W x H), `hit_box` (one code per cell, rows joined by `/`; codes in [`../world/interiors/rooms/README.md`](../world/interiors/rooms/README.md)), `role`, `placeholder` (PNG under `../world/interiors/rooms/`), `used_in` and `areas` (written by `blockout index` from the yamls' `room:` blocks), `status`, `tool` (empty: the room tool does not exist yet), `description`, `vanilla`, `reference_art`, `notes`. No art yet (2026-11-04). |
| `world_kits.csv` | everything else the world needs drawn: field objects, floor mechanics, doors, warps, animated tiles, the underwater kit, battle backgrounds, hideouts and decorations, map popups and the StarNAV map, field effects, weather, map borders, story props, interactive tiles; one row per item and planet | `kit_id` (`kit:<category>:<planet>:<item>`), `category`, `planet`, `item`, `name`, `emerald` (the vanilla piece it replaces), `drawn`, `hit_box`, `used_in` and `areas` (written by `blockout kits` / `index` from a scan of the yamls and `../game`), `status`, `tool`, `description`, `notes`, `placeholder` (PNG under `../world/kits/`). Categories in [`../world/kits/README.md`](../world/kits/README.md). |
| `sand_skim_rules.csv` | who can learn SAND SKIM, the Dune Sea field move | `kind` (`type` or `species`), `value` (a type such as `GROUND`, or a species constant such as `PONYTA`), `learns` (`YES`), `reason`. A species row wins over its types. `tools/sand_skim.py` applies it to every species: `database/sand_skim.csv`. |
| `dune_sea_swaps.csv` | the Dune Sea's own wild table: species swapped in Tatooine's sea slots (no fishing on the Dune Sea) | `from_species`, `to_species`, `maps` and `slots` (pipe-separated; empty = every map or slot; the most specific row wins), `reason`. Slots, levels and rates stay Emerald's. `tools/sand_skim.py` writes `database/dune_sea_encounters.csv` and checks `../game`; `--install` writes the game's tables. |
| `npcs.csv` | NPCs that are a named character, and gifts no object event starts | `npc_id` (`npc:<map>:<n>`, n = the object event's local id on that map, see `database/npcs.csv`), `character_id` (a `character:*` row in `characters.csv`), `scripts` (pipe-separated script labels this NPC delivers that a map script runs, such as OWEN's `PetalburgCity_WallysHouse_EventScript_GiveHMSurf`), `notes`. Seeded by name match on 2026-11-03; add a row for every new or re-cast NPC. Read by `tools/obtain.py`. |
| `obtain_extra.csv` | gifts the game's scripts don't show, and net-new gifts | `obtain_id`, `kind`, `what` (wiki id; pipe-separated for a choice), `sw_name`, `quantity`, `npc_id`, `map_id`, `flag`, `after_script` and `after_what` (the vanilla gift it comes right after; it takes that row's map, flag and story order), `notes`. Example: HM09 from OWEN after HM03. |
| `obtain_order.csv` | story order the scripts can't show | `script` (one script) or `map_prefix` (every map starting with it), `badges`, `story_event` (a `timeline_events.csv` id), `reason`. |
| `trainers.csv` | 489 generic trainer names | `key` (`name:<EMERALD NAME>` shared by rematches, or a `trainer:<id>` override, used for the 53 GRUNTs), `emerald_name`, `sw_name`, `notes`. Seeded by `tools/gen_trainer_names.py` (same first letter and gender, deterministic); edit freely, re-runs only add missing rows. |
| `timeline.csv` | 45 story events | `emerald_event_id, sw_title, sw_tagline, sw_description, sw_lore, planet, map_status` |
| `texts/*.csv` | curated dialogue | `text_id, sw_text_raw, notes`. Keep Emerald's control codes (`\n`, `\l`, `\p`, `$`, `{PLAYER}` …). Generated from `texts/specs/*.py` with `tools/curate_texts.py` (edit the spec, re-run); the CSV is what the build reads. `texts/lang_01_alien_npcs.csv` is written by hand: the alien-language lines ([`../bible/ALIEN_LANGUAGES.md`](../bible/ALIEN_LANGUAGES.md)), each with its meaning and source in `notes`. |
| `asset_inventory.csv` | 1,087 sound and VFX assets | **Generated** by `tools/scan_game_assets.py` from `../game`; never edit. One row per music track, sound effect, phoneme, cry, battle status/general/special animation, field effect, weather and battle transition, with `source_file` / `source_line`, `asset_file`, `refs` (where the game uses it) and `used_by` (maps, moves, species, sprite tags). |
| `name_refs.csv` | every game line that names the player, the rival, Prof. Korr or Dexter | **Generated** by `tools/scan_name_refs.py` from `../game`; never edit. `character` (a `characters.csv` id), `kind` (`text` the player sees, or `code`: identifiers in one file, `count` uses, examples in `text`), `status` (`SWAPPED`, `OLD` = still shows the Emerald name, `KEEP` = code left as is), `old_term` / `new_term`, `source_file` / `source_line`, `label` (the text's symbol), `text`. `--check` exits 1 while any `OLD` row is left. |
| `descriptions.csv` | hand-written item, move, ability, fruit and decoration descriptions | `game_file`, `symbol` (the C string in `../game`), `sw_text` (Emerald control codes, `\n` per box line), `notes`. Read by `tools/port_terms.py`; wins over its automatic term swap. |
| `audio.csv` | every music track and sound effect, cry overrides, net-new audio | `asset_id` (inventory id or `net:*`), `sw_constant` (new song constant), `swap_kind`, `map_status`, `audio_status`, `priority` (1 heard constantly, 2 story moments, 3 rare), `sw_subject` (the brief for the composer / sound designer), `placeholder_from`, `replaced_by`, `depends_on`, `notes`. Cries without a row are derived from `species.csv`. A net-new sound installed in `../game` (e.g. `SE_BLASTER_BOLT`) keeps its `net:*` row: the inventory row under its new constant needs no row here, the build attaches its source line and refs to the `net:*` row (matched by `sw_constant`). |
| `music.csv` | a label for every music row in `audio.csv` / `pending_audio.csv` | `asset_id`, `music_category`, `music_form`, `sw_title` (the song's Star Wars title; blank until named), `planets` (extra planets, pipe-separated, for songs a script plays), `tech_notes` (plain notes for whoever makes the song), `maps` (pipe-separated map ids a net-new song takes over, such as a per-planet split of a song Emerald shares across planets; shown as `planned_music` in `database/music_by_map.csv`). `ref_use` (`ARRANGE`, `STYLE` or `SCRATCH`), `ref_tracks` (pipe-separated `soundtrack:<album>:<NN>` ids from `music/soundtrack_tracks.csv`, main reference first) and `ref_notes` (which part of the cue): the film cue each song is made from, see [`../music/README.md`](../music/README.md). Categories: `FRONT_END` (title, intro, crawl, credits), `TOWN`, `ROUTE`, `TRAVEL` (surf, bike, ship rides, hyperspace), `DUNGEON`, `BUILDING`, `FACILITY` (Grand Arena, Showcase), `MINIGAME`, `EVENT` (scripted story moments), `ENCOUNTER` (trainer eye-contact), `BATTLE`, `VICTORY`, `FANFARE`, `SYSTEM`, `UNUSED` (ghost rows). Forms: `LOOP` (a song that repeats), `AMBIENT` (an atmosphere loop, little melody), `CUE` (plays once, timed to a scene), `JINGLE` (a few seconds, then the old song resumes), `SILENT`, `NONE`. A new music row in `audio.csv` needs a row here too (`tools/build_music.py` warns). |
| `vfx.csv` | every VFX inventory row, net-new VFX, ghost overrides for existing art rows | `asset_id`, `swap_kind`, `map_status`, `art_status`, `sw_subject`, `placeholder_from`, `replaced_by`, `depends_on`, `notes`. A row whose id is a `pending_art.csv` asset (e.g. `graphics/unused/*.png`) overrides that row. |
| `branding.csv` | every title screen, intro, credits, cutscene and menu image, plus `brand:*` rows | same columns as `vfx.csv` plus `todo` (`HUMAN-TODO` = replace by hand, no tool) and `path` / `source_line` for `brand:*` rows (e.g. the ROM title in `Makefile`). Overrides those rows in `pending_art.csv`: `HOTSWAP` + `HUMAN-TODO` where Pokémon branding must go, `KEEP_ART` for generic UI. |

Name limits: creature 10, move 12, item 14, ability 12, type 6, trainer
class 12, trainer name 10, map name 16.

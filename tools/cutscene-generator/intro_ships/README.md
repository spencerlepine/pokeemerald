# intro_ships

Ship silhouettes for the intro's scene-1 fly-by sprite (`game/graphics/intro/scene_1/flygon.png`,
64x32, one colour, flown by `SpriteCB_FlygonSilhouette` in `game/src/intro.c`). Round 1: five hero
ships (A1-A5) and five Imperial ships (B1-B5); the owner picks one of each and both fly by.

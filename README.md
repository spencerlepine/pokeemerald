## Project Structure

| Path | Contents |
| --- | --- |
| [`game/`](game/) | C lang game source code (originally decompiled by this team: [pret/pokeemerald](https://github.com/pret/pokeemerald)) |
| `tools/` | Various scripts and frameworks to help an LLM generate game assets from scratch |
| `wiki/` | Collection of `.csv` files that document the entire game lore (creatures, planets, dialog, etc.) |
| [`.github/`](.github/) | CI workflows to build/test/lint |
